# Skills do music-tutor

Skills do Claude usadas para escrever, revisar e ensinar com as aulas deste repositório.
O Claude Code carrega automaticamente as skills desta pasta quando trabalha no repositório.

- `redator-de-aula`: escrever ou ajustar uma aula JSON, da abertura aos exercícios.
- `revisor-musical`: conferir teoria, fontes, direitos autorais, notação e pedagogia antes de publicar.
- `modo-perguntas`: tutoria no chat, com uma pergunta por vez, dicas em escada e revisão espaçada.
